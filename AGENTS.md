# Coding Agent Instructions

## Project

SmartQueue is a web-based queue management system.

## Development rules

- Follow the tasks defined in TASKS.md.
- Review PLANNING.md before implementing a feature.
- Keep the frontend and backend separated.
- Use clear and descriptive names for files, variables and functions.
- Validate all incoming API data.
- Do not store passwords as plain text.
- Write tests for critical business operations.
- Run the tests before completing a task.
- Make small and meaningful Git commits.
- Document important technical decisions.

## Architecture

- Frontend: React with Vite
- Backend: Node.js with Express
- Database: PostgreSQL
- Testing: Jest and Supertest
- Containers: Docker and Docker Compose
- CI/CD: GitHub Actions

## Git rules

- The main branch must remain operational.
- New features must be developed in separate branches.
- Commit messages must briefly describe the completed change.
- Tests must pass before a feature is merged into main.
