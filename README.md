# SmartQueue

Το SmartQueue είναι ένα διαδικτυακό σύστημα διαχείρισης ουράς αναμονής.

Η εφαρμογή επιτρέπει στους πελάτες να εκδίδουν ηλεκτρονικό αριθμό
προτεραιότητας και να παρακολουθούν την κατάσταση της αναμονής τους.
Οι υπάλληλοι μπορούν να καλούν τον επόμενο πελάτη, ενώ οι διαχειριστές
μπορούν να διαχειρίζονται υπηρεσίες, γκισέ και χρήστες.

## Βασικές λειτουργίες

- Έκδοση ηλεκτρονικού αριθμού προτεραιότητας
- Προβολή των ατόμων που προηγούνται
- Εκτίμηση χρόνου αναμονής
- Κλήση επόμενου πελάτη
- Διαχείριση υπηρεσιών και γκισέ
- Καταγραφή στατιστικών εξυπηρέτησης
- Έλεγχος πρόσβασης ανάλογα με τον ρόλο του χρήστη

## Ρόλοι χρηστών

- Πελάτης
- Υπάλληλος
- Διαχειριστής

## Τεχνολογίες

- React και Vite
- Node.js και Express
- PostgreSQL
- Jest και Supertest
- Docker και Docker Compose
- GitHub Actions
